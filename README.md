# Urban View Impact

신축 예정 건물을 선택하면 주변 건물의 **층별 조망률(한강·남산 등)이 신축 전·후 얼마나 줄어드는지** 브이월드 3D 지도 위에 보여주는 웹앱. 분석 범위는 서울.

## 사용 흐름
오른쪽 패널의 ①→②→③ 단계를 따라간다. **펼쳐진 단계가 곧 지도 클릭 동작**이고, 화면 위 안내 문구가 지금 할 일을 알려준다.

0. 왼쪽 위 검색창에 지역·장소(예: 여의도, 한남동) → 결과 클릭 시 그 위치로 이동
1. **신축 부지**: 새로 지을 자리의 건물 클릭 → 신축 층수·층고 입력 (파란 매스로 미리보기)
2. **조망 대상**: 한강을 따라 2~3번 클릭 → 점 사이 20m 간격 자동 채움. `＋ 남산타워` 버튼. 부지 3km 이내만
3. **분석**: 반경 슬라이더 → `조망 분석 실행`
4. 결과: 핵심 지표(현재 조망 있는 건물, 조망 줄어드는 건물, 최대 감소, 신축 건물 평균 조망), 색 기준(조망 감소 / 현재 조망 / 신축 후), 건물별 층별 전·후 막대그래프, 감소 순위. 3D 건물 클릭 시 해당 건물 그래프

왼쪽 아래 `실사 건물` 스위치로 브이월드 실사 건물 ↔ 단순 매스 전환. `?` 버튼은 사용법.

## 계산 (`viewimpact.py`)
모든 높이는 해발(지형) 기준.

| 항목 | 식 |
|---|---|
| 관찰점 | 건물 GL + (층−1) × 층고 + 1.5 m |
| 건물 지붕 | 건물 GL + 지상층수 × 층고 |
| 조망대상 | 대상 GL + 대상 높이 |

- 관찰점 → 조망대상 시선이 지나는 각 건물 구간에서 시선 높이 < 지붕이면 가려짐 (지구 곡률 보정)
- 조망률 = 가려지지 않은 조망대상 점 비율. 신축 전·후 차이 = VIEW IMPACT
- GL은 브라우저가 브이월드 지형에서 추출해 서버로 보낸다
- 결과는 법적 조망권 판정이 아니라 조망 감소량과 위치를 보여주는 설계 검토 자료

## 데이터
| 항목 | 출처 |
|---|---|
| 건물 외곽선·지상층수 | 브이월드 2D 데이터 API `LT_C_SPBD` (서버 함수) |
| 3D 실사 지도·지형 | 브이월드 WebGL 3D 지도 API 3.0 (Cesium 기반) |

## 한계
- 건물은 층수 × 층고의 박스 모델 (옥탑·경사지붕 없음)
- 신축 부지는 기존 건물을 골라 높이만 바꾸는 방식
- 실사 모드에서 부지의 기존 브이월드 모델만 따로 숨길 수 없다 (레이어 단위로만 켜고 끔)
- 조망 영향은 부지가 관찰 건물과 조망대상 사이에 있을 때만 생긴다. 조망대상에서 먼 내륙 부지는 가리는 폭이 좁아 감소가 거의 없다
- 시선 중간의 언덕 가림은 로컬 DEM(`VIEW_DEM`) 사용 시에만 계산

## 로컬 실행
```bash
pip install -r requirements.txt
python viewimpact.py demo                         # 계산 자체검증
VWORLD_KEY=발급키 python viewimpact.py serve       # http://localhost:8000
```

## 배포 (Vercel)
- `node build.mjs`가 `index.html`의 `{{VWORLD_KEY}}`를 환경변수로 치환해 `public/`에 출력
- `api/buildings.py`, `api/analyze.py` → `viewimpact.py`의 `Handler` (Python 서버 함수)
- 함수 지역 `icn1`(서울): 브이월드 API가 해외 접속을 막을 수 있어서
- Vercel 환경변수 `VWORLD_KEY` 필요. 브이월드 인증키의 서비스 URL에 배포 주소를 등록해야 3D 지도가 뜬다
